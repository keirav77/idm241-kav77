Type of File Dropdown button

TRIGGERS

  • Hover ON:
  • Hover OFF:
  • Click ON:
  • CLick OFF:

Rules

  • Hover ON:
    • Cursor changes to pointer
    • Button state changes to gray
  • Hover OFF: Cursor changes to white
    • Pointer changes to cursor
    • Button state changes back to white
    • CLick ON: Dropdown list appears
    • Click OFF: Menu disappears

    Feedback

    • Hover ON:
      • Cursor changes to pointer
      • Button state changes to gray
    • Hover OFF: Cursor changes to white
      • Pointer changes to cursor
      • Button state changes back to white
      • CLick ON: Dropdown list appears
      • Click OFF: Menu disappears

      Loops and Modes

      Loops: None

      Modes: None
