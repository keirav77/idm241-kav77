1. Adding Star to File

To find this: On google drives home page click on the 3 dots: Hover on the option, "Organize" and then add to stared will pop up as an option. Click that to star a file.

Triggers

  • Hover ON
  • Hover OFF
  • Click ON
  • Click OFF

Rules

Hover ON

  • Cursor changes from arrow to pointer
  • Add to Star collection button turns gray
  • Icon shakes a little when the cursor is hovering

Hover OFF

  • Cursor changes back to Arrow
  • Button color resets to white
  • Icon is still

Click ON

  • Can click Opption + Command + S to click
  • Black filled star is added next to the name
  • Notification pops up at the bottom
  • File you select is blue

Click OFF

  • Click Remove Starred Removes heart
  • Message pops up that says "Removed from Starred

Feedback
