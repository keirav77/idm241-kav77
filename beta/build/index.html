Rules

  • Hover ON:
    • Button changes color to a blue-gray
    • Cursor changes to pointer
  • Hover OFF:
    • Button changes color to white
    • Cursor changes back to default arrow
  • Click ON:
    • Arrow does a 3d rotation to point downward
    • Menu items fade briefly upward and then switch to Z-A format
  • Click OFF:
    • File names sort back to A-Z
    • File list fades briefly upward when sorting
    • Arrow flips 3d upwards again
