Septa Real-Time Map Micro-interaction: Assignment Alpha

How to Access Real-Time Map

Using the link and then click real time map, then put in a septa line, or route: https://www.septa.org Then clicking on the real time map button, click the certain line or mode of transportation you want then see where they are.

1. Describe how user can locate one object on that web

  • User clicks on real time map after opening Septa's website
  • The map is blank at first have to pick a certain route or line.
  • Once the user selects a route the map will update and show markers of where they are moving.
  • User moves cursor over to a vehical marker and clicks on it to show additional information about next stops, where it's going an if theres any delays

2. Triggers

  • User looks at the vehicle marker
  • 1. Hover on 2. Hover off 3. Click on 4.Click off

3. Rules

  • Hover on dot: changes from a grab hand to a pointer
  • Hover off changes from pointer to grabbing-hand
  • Click on- Marker responds with a message popup that shows train number, information about next stop and inbound or outbound, and message about if it's delayed or on time.
  • Click on- The interface responds with zooming into that specific vehicle as well.
  • Click off- The pop up message disappears. Does not zoom back out.

    • Vehicle Marker — Default / Not Selected

    • Hover ON
      • Cursor changes to Pointer
      • Vehicle marker remains visible
    • Hover OFF
      • Cursor changes back to the map cursor
    • Click ON
      • Vehicle becomes selected
      • Information popup appears
      • Popup displays vehicle-specific information
      • Map zooms in toward the selected vehicle

      • Vehicle Marker — Selected

    • Hover ON
      • Cursor changes to Pointer
      • Current vehicle information remains displayed
    • Hover OFF
      • Cursor changes back to the map cursor
      • Current vehicle information remains displayed
    • Click OFF
      • Information popup disappears
      • Map remains at its current zoom level
    • Click Different Vehicle Marker
      • Previously selected vehicle information disappears
      • Newly selected vehicle information appears
      • Map moves/zooms to the newly selected vehicle

      • 4. Feedback

      Vehicle marker- Default/ Not selected

      • Hover ON
        • Cursor changes to Pointer, indicating the marker is clickable
      • Hover OFF
        • Cursor returns to the map cursor
      • Click ON
        • Information popup appears
        • Vehicle number and trip information are displayed
        • Next stop/direction information is displayed
        • On-time or delay information is displayed
        • Map zooms toward the selected vehicle
      • Vehicle Marker — Selected
        • Click OFF
          • Popup disappears
          • Map does not automatically zoom back out
        • Click Different Vehicle Marker
          • Popup changes to the newly selected vehicle's information
          • Map changes focus to the newly selected vehicle
      • Real-Time Feedback
        • Vehicle markers change position as SEPTA receives updated location data
        • The user does not need to refresh the page to see updated vehicle positions

        • 5. Loops and Modes

        Loops:

        Vehicle Marker - Loops

        - N/A — Selecting a vehicle does not initiate a user-controlled repeating interaction. The vehicle's location updates automatically in real time.

        • Map Modes - Default state: Empty map with no line selected - Train selection mode: Search bar drops down different lines - Selected mode: Once a line is selected its route is highlighted and the stops or vehicles are displayed.

        Not Selected Mode

        Vehicle marker is visible on the map - No vehicle-specific popup is displayed

        Selected Mode

        - Vehicle-specific popup is displayed - Map is focused/zoomed toward that vehicle - Selected vehicle information remains visible until the user clicks off or selects another vehicle

        Switching Selected Vehicle

        - Clicking another vehicle changes which marker is in Selected Mode - Previous vehicle returns to Not Selected Mode - Only one vehicle can have its information displayed at a time
