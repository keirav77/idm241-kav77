IDM241: Alpha Description

Beta Description

Left Navigation panel resize

TRIGGERS

  • Hover ON
  • Hover OFF
  • CLick ON+ HOLD
  • Click OFF

Rules

  • Hover ON: Cursor changes to horizontal resize icon
  • Hover OFF: Horizontal resize icon goes back to cursor
  • Click ON + HOLD: Able to widen the navigation bar or make it slimmer
  • CLick OFF: Sidebar stays

Feedback

  • Hover ON: Cursor changes to horizontal resize icon
  • Hover OFF: Horizontal resize icon goes back to cursor

New button

TRIGGERS

  • Hover ON
  • Hover OFF
  • CLick ON+ HOLD
  • Click OFF

Rules

  • Hover ON: Button Changes color to darker gray and cursor changes to pointer
  • Hover OFF: Button returns to default state
  • CLick ON: Selection Menu appears with different available tasks
  • Click OFF: Selection list disappears
